# Reglas de Proyecto: Fabricio Sotelo · Creative Studio (Freelance)

## Regla 1: Image to Code (Captura -> Recreación Fiel)
Cuando el usuario proporcione una captura o imagen de un diseño:
- Recrearlo con total fidelidad en HTML semántico y CSS moderno.
- Respetar milimétricamente el espaciado (escala de 8px), tipografía, jerarquía visual, paleta de colores, sombras y radios de borde.
- Extraer tokens visuales exactos y evitar soluciones genéricas o plantillas automatizadas ("AI slop").

## Regla 2: Verificación Visual con Navegador
Después de construir o modificar cualquier interfaz:
- Abrir la página en el navegador local o mediante el servidor local.
- Tomar o verificar capturas en viewport de escritorio (1280px+) y móvil (375px/390px).
- Auditar minuciosamente la consola para descartar errores JS, fuentes no cargadas, desbordamientos horizontales o problemas de contraste.
- Corregir cualquier desalineación o detalle visual antes de confirmar la finalización al usuario.

## Regla 3: Criterio Anti "AI Slop" & Taste
- Prohibido el uso de patrones genéricos de IA: titulares centrados repetitivos sobre degradados violetas cliché, tarjetas flotantes idénticas sin jerarquía o cajas de iconos vacías.
- Utilizar tipografías con carácter, composición asimétrica intencional, espaciado que respire y contraste verificado (mínimo WCAG AA).
- Enriquecer cada sección con sustancia real: métricas tangibles, demostraciones interactivas, microinteracciones cuidadas y llamados a la acción claros.
